What is this project?

A mini core banking system: the engine that keeps customer accounts, balances and transactions correct.

🏦 What is core banking?

“Core banking” is the central software a bank runs on. Every ATM withdrawal, UPI payment, net-banking transfer or branch deposit ends up as an operation on this core: check the balance, move the money, record it. Real systems (Finacle, Flexcube, TCS BaNCS) work on the same ideas as this project.

🎯 Why does it matter?

Money must never be created, lost or double-spent, even if the server crashes mid-transfer or two people pay at the same moment. This project shows how a database guarantees that using transactions, locks, constraints and triggers.

🌍 Where is it used?

Banks, NBFCs, credit unions, wallets (Paytm, PhonePe), payment gateways, brokerages and any app holding balances: gaming credits, ride wallets, loyalty points.
